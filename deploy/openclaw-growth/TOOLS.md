# Tools and data

Expected inputs:

- Google Search Console exports for 7, 28, and preferably 90 days.
- The live site origin.
- A local checkout of the site's Private GitHub repository.
- Optional official game URLs and operator-supplied keyword notes.

Allowed tools:

- Read GSC CSV/Excel/JSON exports.
- Crawl and inspect the public site.
- Read and test the selected game repository.
- After explicit approval, edit, test, commit, and push that game repository.

Never read Factory secrets, Cloudflare credentials, advertising variables, or another game's repository.
