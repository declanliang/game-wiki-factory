# v1_0730

`v1_0730` 是 2026-07-30 确认的稳定生产版本，面向之后由 Factory 新建的 Cloudflare Pages 游戏 Wiki。它继承 `v1_0728` 的内容、语言和发布契约，并固定本轮已经通过实际站点验收的广告与页面布局规则。

## 继承的生产契约

- 新站只生成并完整 QA `en/es`，首次只公开英文；西班牙语在第三个后续自然日 `10:00 Asia/Shanghai` 自动发布。
- `de/fr/ja` 只保留模板能力，必须由 Growth 专项根据真实搜索需求和用户批准扩展。
- 每个新站使用 Private GitHub repo 和连接 `main` 的 Git-integrated Cloudflare Pages 项目。
- Production 自动设置 `NEXT_PUBLIC_SITE_URL`；自定义域名绑定和 DNS 仍由运营者处理。
- 页面规划、证据门、最多 8 个分类和当前 Codes/Tier List/Updates/Entity/Guide 内容形态均沿用 `v1_0728`。

## 本版本固定的变化

- Shared Adsterra profile 继续使用原有 8 个 server-only `AD_*_B64` 变量；变量名、Base64 转换和 Cloudflare provisioning 语义没有变化。
- 顶部广告与导航同时固定时使用不透明背景和独立高度，不允许滚动重叠。
- 首页广告只能位于完整 section 之间，不能插入 Featured 卡片网格。
- 分类页至少 4 张卡片时只显示一个 Native；不再显示分类首尾横幅或额外 300×250。
- 文章侧栏广告移到左侧；内文广告只使用直属段落并避开 Callout、表格、嵌套结构和文章末尾。
- 页面底部统一只保留一个响应式全局广告，不叠加文章或分类专属广告组。
- 首页、Hero、Header、分类页、视频和 Footer 的最大内容宽度小幅收紧；文章正文保持 760px 阅读宽度。

完整广告变量与展示预算见 [Adsterra 共享 Profile 与环境变量合同](../advertising/adsterra-environment-contract.md)。

## 上线认证

一个新站只有同时满足以下条件才可称为 `v1_0730`：

1. `intake/factory-release.json.release` 为 `v1_0730`。
2. GitHub repo 为 Private，Cloudflare Pages 连接该 repo 的 `main`。
3. 英文首次部署及后续西班牙语发布分别通过 metadata、canonical、robots、sitemap 和全部公开 loc/hreflang 验收。
4. `result.localePublication` 明确记录生成语言、当前公开语言和第三个后续自然日发布策略。
5. Pages 项目保留完整 8 个广告变量及 Production `NEXT_PUBLIC_SITE_URL`，且不覆盖其他非受管变量。
6. 广告 iframe 数量、响应式格式、区块隔离和 Footer 单广告符合本版本展示预算。

`v1_0730` 不自动迁移或覆盖历史站点。已经认证为 `v1_0728` 或更早版本的站点继续保留原认证；只有显式使用新模板更新并完成验收后，才可重新登记为本版本。
