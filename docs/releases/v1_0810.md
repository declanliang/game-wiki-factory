# Factory v1_0810

发布日期：2026-08-10

## 本版本范围

- 以稳定的 `v1_0730` 生产合同为基础，修复 Next.js 根布局：`src/app/layout.tsx` 负责唯一的 `<html>/<body>`，`[locale]/layout.tsx` 不再重复声明根元素。
- 首页、文章页、导航、主题色、图片、YouTube 视频和广告区块完成通用模板优化。
- 保持 Cloudflare Workers Static Assets 为新站默认托管方式；不创建新的 Cloudflare Pages 项目，也不回迁 Vercel。
- 新站默认生成 `en/es`，首次只公开 `en`，按既有发布计划第三个自然日发布 `es`。
- 保持共享 Adsterra profile 和 8 个 `AD_*_B64` Worker 变量合同不变。
- Roblox Basic Info 在 `games.roblox.com` 返回策略性 403 时，回退到官方 `develop.roblox.com/v1/universes/{universeId}`，不降低证据门。
- 忽略 `Not specified` 等占位值，不把它们升级为事实；多语言 locale 对可选事实字段保持一致结构。
- SEO 验收继续要求根路径 301 到 `/en`、self-canonical、sitemap/hreflang、robots、metadata、图片和广告 wrapper 全部通过。

- 20 个公开页面、40 个 sitemap hreflang 目标；

- Cloudflare Workers Static Assets 部署和线上验收通过；
- Private GitHub：`declanliang/grow-a-chicken-fighter`；
- 正式域名：`grow-a-chicken-fighter-roblox.top`；

## 接手注意

以后新游戏按 `README.md` 的 JSON 配置提交，默认使用 Workers Static Assets。服务器上的 OpenClaw 只负责提交和查询，Worker/Supervisor/Agent2 按既有边界执行；Agent2 只修单站产物和 checkpoint，不改 Factory、不推送 GitHub、不执行 Cloudflare 发布。
