# v1_0728 本地候选版本

`v1_0728` 面向未来新建的 Cloudflare Pages 游戏 Wiki。当前先在
`release/v1_0728` 本地分支验证；用户确认前不推 GitHub、不部署服务器。

## 主要变化

- 五语言仍一次生成和完整 QA，但首次公开只有英文。
- 固定顺序 `en → es → de → fr → ja`；每次成功后，第三个后续自然日
  `10:00 Asia/Shanghai` 发布下一个语言。
- 语言发布是 SQLite 中的内部可重试任务；它只提交 Private GitHub 的
  `intake/publication-plan.json`，Cloudflare Pages Git 集成自动部署。
- sitemap、hreflang、语言切换器和静态路由只包含当前已公开语言。
- 页面规划增加 primary keyword、研究查询、用户问题、必答点和独特价值。
  允许少量共享背景；只有错误游戏/无关内容会删除，意图偏弱页面保留并记录。
- 首页优先把用户导向真实任务页；文章、精选卡片和相关推荐可使用 Basic Info
  获取的 Roblox/Steam 官方图片。
- 站点主题从 6 个对比度约束预设中按游戏语义稳定选择，不接受任意模型颜色。
- GSC 核心词增长从 Factory 分离，由独立 `game-wiki-growth` OpenClaw Agent
  先审计、经批准后修改单个游戏 repo。

## 上线认证

一个站点只有同时满足以下条件才可称为 `v1_0728`：

1. `intake/factory-release.json.release` 为 `v1_0728`。
2. 初始 GitHub repo 是 Private，Cloudflare Pages 为 Git-integrated `main`。
3. 英文生产部署、metadata、canonical、robots、sitemap 和所有公开 loc/hreflang
   目标通过验收。
4. `result.localePublication` 明确记录生成语言、当前公开语言和发布策略。
5. 后续 localeRelease 每次只增加一个语言并通过线上验收。

本版本不迁移历史站、不处理 Vercel、不处理广告环境变量，也不加入站内搜索。
