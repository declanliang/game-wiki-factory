# v1_0722 稳定版本与站点清单

`v1_0722` 是 2026-07-22 确认的稳定生产版本。版本号来自仓库根目录 `release.json`，与 Git commit 解耦：日常修复、文档和运维提交不会自动产生新版本；只有用户明确决定发布新版本时才修改它。

## 认定标准

站点必须同时满足以下条件才属于 `v1_0722`：

1. 由当前完整新建或 `operation: rebuild` 流程生产；旧项目普通续跑不会获得版本标记。
2. 仓库中存在 `intake/factory-release.json`，其中 `release` 为 `v1_0722`。
3. 构建、内容 QA、GitHub Private 检查、Vercel 部署及线上 sitemap/robots/canonical/链接验收全部成功。
4. 已登记在 [v1_0722-sites.json](v1_0722-sites.json) 的 `certifiedSites` 中。

日期接近、页面外观相同或文章数量较多，都不能单独作为版本依据。

## 维护规则

- 每次新站/重建成功后，由后台任务把 release、repo、Vercel project、production URL、Git SHA 和线上验收时间写入清单。
- 失败、仅本地完成或线上验收未通过的站点不得进入 `certifiedSites`。
- OpenClaw 汇报成功时必须包含 `factoryRelease`；没有该字段时应报告为旧站/未认证，而不是推断版本。
