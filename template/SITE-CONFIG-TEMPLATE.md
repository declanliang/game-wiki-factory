# 站点配置信息清单（AI 内部对照用，不是用户填写表单）

**这份文件是 AI 翻译用户原始素材时自查用的清单，不需要用户手动填写。** 正常流程里，用户提供的是走 ChatGPT 调研流程产出的原始文档（格式不限，比如 Markdown 里嵌 JSON 块），AI 拿到之后对照下面每一条，自己做字段映射、格式转换，生成 `intake/site-content.json`。完整字段定义见 [doc/homepage-info-schema.md](doc/homepage-info-schema.md)。

只有一种情况才把下面的问题列表原样发给用户当访谈提纲：**用户完全没做任何调研、要 AI 直接逐项询问收集信息**。这种情况下把 `[ ]` 当成要问用户的问题，用户不确定的可以回答"不知道/沿用默认"，AI 用模板已有的占位内容或合理默认值兜底。

不管走哪种情况，**事实性信息（游戏名字、机制、数值、外部链接）不能由 AI 编造**——原始素材/用户回答里没有的，就留空或用占位值，在交付说明里列出待补充清单。

> About 区段落（第 1 节站点描述会用于生成 `aboutGame.paragraphs`）支持用 `**关键词**` 高亮游戏名/开发商/核心机制等重点词，参考截图里 Farever 案例的效果。Hero 区的信任标签（`hero.stats`）固定展示 4 个，超过 4 个只取前 4 个。**`hero.stats` 和 `aboutGame.stats`（Quick Facts）分工不同，别填重复的数字**：`hero.stats` 放"新鲜感/热度"类（访问量、更新日期、服务器人数），`aboutGame.stats` 放"事实规格"类（开发商、平台、类型、核心机制），两边不要出现同一个数字（比如访问量只在 `hero.stats` 出现一次，`aboutGame.stats` 不要再放一遍）。

## 6. 首页——精选内容区 + 时效性工具区 + 分类精选区（`home.featured` / `home.liveTools` / `home.extraSections`）

**这三个都是轻量卡片列表（图标+标题+一行描述+链接），不是带完整预览的大 section，条数不固定，按实际有价值的内容给多少填多少，不用凑数到某个数字。**

**6a. 精选攻略（`home.featured`，不需要用户填）**：这个模块由 AI 在文章接入后按固定规则自动从已收录文章里挑（每个分类优先挑入门向文章，不够 4 篇会同分类补选，上限 8 篇），不是编辑判断，不需要用户在这里指定候选清单。**只有用户明确想指定某几篇具体文章**才需要填下面这几项，不填就完全走自动规则：

- [ ]（可选）
- [ ]（可选）

（填了的话，每条给：标题 / 一行描述 / 对应文章链接 / 所属分类 key（可选，用于自动匹配分类图标））

**6b. 时效性工具（`home.liveTools`，可选，没有就整个跳过不生成这块）**：兑换码、梯度榜、服务器状态这类需要经常更新的页面。没有这类内容的游戏，这一节完全不填、不生成，首页不会留空标题或空白区域。

- [ ]（没有就写"无"，整块跳过）

**6c. 分类精选区（`home.extraSections`，可选，可以有 0 个、1 个或多个块）**：首页唯一的开放扩展点——把某个内容分类里真实、具体的条目（角色名、职业名、道具名……而不是"共 N 篇攻略"这种统计数字）直接列在首页，一眼可见核心信息，同时提升首页关键词密度。只给内容量足够、值得首页单独展示的分类做一块（比如角色、职业、道具、异常这类条目式内容），"guide"这种攻略型分类已经有精选攻略/分类导航/Latest Updates 三个区块覆盖，不需要在这里重复。每块 4-8 条，太少（1-2 条）不值得单独开一块。
